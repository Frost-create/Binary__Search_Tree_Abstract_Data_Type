# Binary__Search_Tree_Abstract_Data_Type
Binary Search Tree in C
This project implements a Binary Search Tree (BST) in C using dynamically allocated, pointer-linked nodes to store and organize numerical data.
How It Works:
• Node Structure: Each node holds a numeric value (key), a frequency tracker (count) to handle duplicate entries efficiently, and pointers to its left and right child nodes.
• Insertion & Sorting: Values are sorted dynamically upon insertion—numbers smaller than the current node are routed to the left branch, while larger numbers are routed to the right branch. Duplicate values simply increment the existing node's count.
